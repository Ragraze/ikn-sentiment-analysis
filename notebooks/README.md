# Research notebooks

Research workflow:

1. `Preprocessing_Datasets_IKN.ipynb`: dataset cleaning and preparation.
2. `Sentimen_Analysis_IKN_IndoBERT.ipynb`: IndoBERT fine-tuning and evaluation.
3. `Topic_Modelling_of_IKN.ipynb`: Top2Vec topics for each sentiment and coherence scores.

Notebook contents and research outputs are preserved. Colab paths saved in the notebooks refer to the original experiment environment. When rerunning locally, point input paths to `../data/` and save new outputs in `../backend/reports/`.

To run the local pipeline without editing the notebooks, use the scripts in `backend/scripts/` as described in the [application guide](../backend/README.md).
